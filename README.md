# Zayy Bot - Discord Multi-Purpose Bot

Un bot de Discord multifuncional con 312+ comandos inspirado en Zayy.

## 🚀 Características

- **30+ categorías** de comandos
- **VoiceMaster** - Sistema de canales de voz temporales
- **Economía** completa con tienda, trabajo, juegos
- **Moderación** avanzada
- **Sistema de tickets**
- **Giveaways**
- **Invites tracking**
- **AI commands**
- **Y mucho más...**

## 📋 Requisitos

- Python 3.8+
- MongoDB (opcional, recomendado para Railway)
- Token de Discord
